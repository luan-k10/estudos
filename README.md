# Estudos — central de matérias

Página inicial para escolher o que estudar. Ela mostra o progresso salvo em cada matéria e tem atalhos diretos para cada seção.

**Acesse:** https://luan-k10.github.io/estudos/

## Matérias

| Matéria | Site |
|---|---|
| Programação Distribuída e Paralela | https://luan-k10.github.io/estudo-programacao-distribuida/ |
| Avaliação e Desempenho de Sistemas Computacionais | https://luan-k10.github.io/estudo-avaliacao-desempenho/ |

## Como funciona

- Cada cartão mostra quantas questões você respondeu e a sua taxa de acerto na matéria.
- O "Seu progresso geral" soma o total respondido, o acerto e as questões para revisar.
- Os atalhos abrem a matéria direto em Resumos, Quiz, Simulado, Flashcards etc.
- Os sites das matérias têm o botão **← Matérias** para voltar a esta página.
- O tema claro/escuro é compartilhado entre todas as páginas.

## Tecnologia

HTML, CSS e JavaScript puros, sem dependências. O progresso é lido do `localStorage` do navegador, que é compartilhado pelos sites em `luan-k10.github.io`. O visual segue o padrão do portfólio.
